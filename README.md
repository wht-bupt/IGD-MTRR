# IGD-MTRR

本仓库目前只放评测说明，不包含代码和数据。

下面记录的是两段完全合成星场上的 IGD-MTRR。底图由星表、高斯恒星、读出噪声和固定暗缝生成，不包含在轨观测。目标按主实验的注入规则绘制。空间特征 64 维，时间特征是四个锚点各自的 P、N、R，共 12 维。权重在真实底图的训练集上得到，在这两段序列上不微调，阈值也不重新挑选。这组数字只描述这个合成集，不替换真实底图上的主结果。

## 目标

每段 20 条轨迹。抽样顺序是：位置、速度、角度、设定信噪比并打乱、拖尾长度、PSF σ，然后每条轨迹的像素扰动。星场和目标用两套独立的随机数。目标种子 seq01 是 20261126，seq02 是 20261127。PSF σ 取 1.35–1.5。

| 项 | 取值 |
|---|---|
| PSF σ | Uniform(1.35, 1.5) |
| 速度 | Uniform(15, 120) 像素/帧，方向 Uniform(0, 2π) |
| 拖尾长度 | Uniform(0, 8) 像素 |
| 设定信噪比 | 7 条 `linspace(3.5, 4.0, 7, endpoint=False)`，13 条 `linspace(4.0, 8.0, 13)`，然后打乱 |
| 像素扰动 | 几何中心 3×3 里抽 0–3 个像素，乘 1±Uniform(0.10, 0.30)。峰值归一之后、干净环定标之前做。中心像素可以被抽到 |

信噪比在注入之前的干净环上标定。环是中心像素周围 11×11 去掉中心 3×3 的 112 个像素。目标水平是设定信噪比乘环标准差，再加环均值。注入范围是印记里达到峰值 20% 以上的像素。尺度取这些像素上 `(水平 − 该像素背景) / 印记` 的最小值。任一亮核像素已经达到或超过这个水平，这一帧就跳过该目标。写进标注的信噪比是设定值；某一帧没画上，是这一帧没有余量。

初始位置避开图像中心十字 ±16 像素，也避开暗缝上下各 16 行。轨迹之间初始间距至少 80 像素，离边界至少 16 像素。前进时若走进中心十字或暗缝带，会被推出去并反向。走出视场后不再重新生成，所以后半段目标变少。没有目标的帧仍参与虚警。

## 评测帧和命中

IGD-MTRR 要用当前帧和前六个历史帧，所以只评第 6 帧到第 94 帧，每段 89 帧，两段合计 178 帧。第 0–5 帧只作历史，第 95 帧不评。两段都没有排除帧。

这 89 帧上的实例：

| | seq01 | seq02 | 合计 |
|---|---|---|---|
| 实例 | 297 | 307 | 604 |
| 低信噪比 3.5–4 | 67 | 65 | 132 |
| 高信噪比 4–8 | 230 | 242 | 472 |
| 没有目标的帧 | 26 | 33 | 59 |
| 最后一次出现目标的帧号 | 69 | 61 | — |

seq01 评测帧上的信噪比是 3.57–8.00，seq02 是 3.50–8.00。

拖线中心线以标注中心为中点，长度为拖尾长度，方向是速度方向。长度为正时，从 −L/2 到 L/2 按 0.5 像素取样再四舍五入，得到中心线上的整数像素。点目标只保留中心像素。检测点先四舍五入，再与这些整数像素做切比雪夫距离，距离 ≤ 1 算候选命中。一对一按该帧真值的书写顺序走，每个真值拿走最近的、还没用过的候选。分数达不到阈值的配对不算命中。

虚警只对全体计算，不按信噪比拆开。公式是 `(检测数 − 命中数) / (帧数 × 3072 × 3072 / 10^6)`。每段 89 帧的分母是 839.91 百万像素，两段合计 1679.82。

## 检测器

空间特征 64 维。时间特征是四个锚点各自的正响应、负响应和重复性，按锚点顺序拼成 12 维，不先平均，也不补零后再复制。融合头是 76→128→64→1。阈值是这套头在真实底图训练集上的 90% 工作点，0.8526737093925476。

每一评测帧的顺序：

1. 用相位相关得到相邻帧平移，再累加当前帧相对前 1 到前 6 帧的位移。
2. 一筛：11×11 减去中心 3×3 的环信噪比。3×3 里信噪比大于 0 的像素至少 7 个，并且 3×3 极大值大于 2.0。返回的坐标向内收 6 像素。
3. 二筛：四个整数锚点上的加权绝对残差取最小，留下前 50000。候选像素乘 8，周围 8 个像素各乘 1。锚点中心出界则该锚点记 0。
4. 空间支路把四个锚点的 9×9 拼成 162 维，编码成 64 维。时间支路在六个历史帧上取每个锚点的 P、N、R，拼成 12 维。64+12 送进融合头，分数只用 sigmoid。
5. 曼哈顿半径 5 做非极大值抑制，再按上面的规则配对。
